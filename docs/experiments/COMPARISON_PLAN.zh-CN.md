# 实验二完成后，怎样与实验一比较？

当前导师报告来自实验一，实验二报告尚待生成。本文件先固定比较问题和对齐要求；现在不填入未经完成评测的优劣结论。

## 先问两边是否具有可比条件

逐项记录并核对公司/目标与cutoff、数据暴露和可得信息、基础模型/服务快照与effort、R/H代码和实际调用顺序、token/tool/wall限制、Review与scorer、尝试/重试规则及总资源。不能只因公司数和模型名相同，就视为严格配对实验。

实验一Round0为3.00，实验二自身baseline为2.98；二者都是各自的对照，不能互换。baseline差异也不是已估计出的随机波动范围。

实验二接入本次反思后受到人工研究设计指导。报告须给出接入位置、首个受影响proposal及后续干预，区分它与原始无此指导阶段。

## 比较五个维度，而不只比最高分

| 维度 | 应报告的证据 |
| --- | --- |
| 预测表现 | 同一冻结候选完整25家，均分/总评分点、相对自身baseline和实际parent的变化、公司/目标级改善与回退、缺失与失败 |
| R研究能力 | 更准确的诊断、区分替代解释的检验、合法可比历史、正确的方法选择或弃权、对下一步决策的实际影响 |
| H工具能力 | 工具确实改变、结果到达正确消费者、实际被使用，且预期行为通过相应检查 |
| 经验继承 | 反馈送达 -> 代码/策略改变 -> 执行 -> 结果 -> 后续复用；同类错误和人工干预是否减少 |
| 效率与树生长 | 每层真实parent/三个科学child、全局生长席位、科学深度与repair attempt分离、有效实验总费用/耗时及停止或阻断原因 |

预测冠军的采用规则与研究节点的生长选择分别比较。小分差应换算成整个面板的评分点；失利分支若解决了问题，也应展示其证据与下一步后果。

## 怎样处理成本、谱系和未完成结果？

两边分别计入proposal、交付修复、Review、失败、预测、验证以及完整pending；技术修复和行政窗口不增加科学子代数。列明各自预算授权和每次资源限制，不将预算相同当成实际资源匹配。

一个真实代码parent可以不同于最新反馈来源或预测冠军。保留历史错序、缺枝和拒绝，不通过重挂节点制造平衡树。

实验二尚未完成的候选写“未完成”，失败或缺失写实际状态，不补零、拼接不同候选或重跑已完成公司。完整结果到达之前，保持比较结论待定。
