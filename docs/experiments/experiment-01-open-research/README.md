R17相对Round0为+0.18/5，相对实际父代为+0.12/5，相对此前冠军为+0.04/5；最后一项对应整个25家面板合计多1个评分点。实际父代、反馈来源和预测冠军须分别显示。

这是反复使用TRAIN25后的Discovery结果。分数采用、具体机制成立、研究能力提升和泛化证据是不同判断。R17记录显示新增采集行为已激活，但尚未验证相应研究能力增益；该获胜分支的候选H未改变。报告同时保留实际做过的H分支，不能由此推断实验完全没有尝试H演化。

## 哪些反思进入实验二？

前瞻研究设计关注三条问题：目标与证据契约是否丢失关键信息；历史缺失是否其实来自不可比/错绑定；反馈和工具结果是否真正进入决策。

这些作为人工新增的方法假设进入实验二，不直接搬运本实验的候选、公司反馈、研究记忆或支出权限。它们需要在实验二自身的合法证据中重新检验。
