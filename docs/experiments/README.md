# 两组共演化实验：当前报告来源与后续比较

我们用两条独立实验轨迹研究同一个问题：自动研究者能否通过反馈改善研究判断、工具使用和预测表现。**当前导师报告来自实验一；实验二继续独立运行，待有完整结果后再与实验一比较。** 本目录保存方法、实验身份和比较口径，避免把不同实验的基准、候选、费用或结论混在一起。

## 两个 experiments 分别是什么？

| 项目 | 实验一：开放研究共演化 | 实验二：原框架独立重启 |
| --- | --- | --- |
| 文档入口 | [实验一及报告来源](experiment-01-open-research/README.md) | [实验二及完整 Prompt](experiment-02-framework-restart/README.md) |
| 当前用途 | 当前导师报告的证据来源 | 独立积累新轨迹，完成后用于比较 |
| 自身完整25家基准 | Round0：3.00/5 | 独立 baseline：2.98/5 |
| 本次记录的候选结果 | 报告快照中的 R17：3.18/5 | 本次发布未纳入完整25家候选结果 |
| 初始代码父节点与基准 | 按实际 R/H 血缘记录；基准单独比较 | R0/H0 scaffold 未评分；2.98 是独立对照，不是父节点得分 |
| 本次反思如何接入 | 形成问题与方法反思 | 作为人工新增前瞻指导，记录首次接入的06及后续安全边界 |
| 数据、费用和运行状态 | 沿用实验一自己的证据与账本 | 沿用实验二自己的证据与账本，保持隔离 |

表格是2026-10-27整理的文档快照，不是实时运行仪表盘，也不是两组已经完成的胜负比较。实验二的 baseline 有25家公司实测分数，其中包含一次明确授权的失败公司新尝试；原失败和费用仍保留。

## 哪些内容已经发布，哪些还没有？

本次发布的是完整研究协议、实验身份、报告入口和预先记录的比较方法。当前导师报告仍是实验一的报告；实验二报告和最终比较尚待生成，届时单独添加，不追写成现在已经发生。

数据、受保护问题/答案、heldout内容、私有模型上下文、运行账本、原始调用日志和凭证不在本次提交中。Google Doc沿用原共享权限；发布链接不会改变访问权限。Git中的文档不创建运行、预算或数据访问授权。
